# HLD Camel

The old Flask/Jinja implementation has been migrated into the Next.js `docs-site` app.

Run the active HLD UI from `docs-site`:

```powershell
cd docs-site
npm run dev
```

Then open `http://127.0.0.1:5173/hld`.

Data now lives in `docs-site/content/hld/problems`, and uploaded images are written to `docs-site/public/hld/uploads`.
